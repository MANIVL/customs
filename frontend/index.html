Заполненный шаблон по входным Excel‑файлам

Загрузите входные файлы — получите готовый шаблон

Приложение находит столбцы во входных Excel‑файлах по заголовкам или через YandexGPT (кнопка «ИИ: сопоставить столбцы») и подставляет данные в эталонный шаблон.

1

Эталонный шаблон

Столбцы шаблона фиксированы и не меняются. По умолчанию используется сохранённый шаблон — при необходимости замените его своим файлом.

2

Входные файлы

Загрузите один или несколько файлов с данными (инвойс, спецификация, упаковочный лист и т.п.). Структура и порядок столбцов во входных файлах могут отличаться — система ищет их по заголовкам.

Перетащите файлы сюда или нажмите, чтобы выбрать
.xlsx / .xls — можно выбрать несколько файлов сразу
    3

    Настройки

    Страна происхождения берётся из входных файлов и записывается кодом ISO (Китай → CN, Италия → IT). Единица измерения тоже ищется в файле (шт → ШТ, пар → ПАР, м → М). Если значение в файле не найдено, используется поле ниже.

    Код МНР определяется автоматически по тексту сертификата, например:

    ЕАЭС RU С‑… → 01401, ЕАЭС N RU Д‑… → 01402, РОСС RU Д‑… → 01408, любой другой номер → 01206.

    Если в строке найдено два документа, они записываются в два блока шаблона.

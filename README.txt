ТаможенФормат — веб-версия
==========================

Что это
-------
Веб-приложение для заполнения эталонного шаблона данными из входных
Excel-файлов. Приложение можно запустить локально или разместить на
облачном сервере, после чего пользователи открывают его обычной интернет-
ссылкой. Шаблон хранится в backend\data.

Установка
---------
Нужен Python 3.11 или новее.

  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt

Запуск
------
В терминале:

  python main.py

Откроется браузер по адресу http://127.0.0.1:8756/

Остановка: Ctrl+C в окне терминала.

Доступ из локальной сети (другие компьютеры в той же сети):

  set APP_HOST=0.0.0.0
  set APP_PORT=8756
  python main.py

Затем откройте http://<IP-этого-компьютера>:8756/

Переменные окружения
--------------------
APP_HOST          — адрес прослушивания (по умолчанию 127.0.0.1)
APP_PORT          — порт (по умолчанию 8756)
APP_OPEN_BROWSER  — 0, чтобы не открывать браузер автоматически
YANDEX_API_KEY    — API-ключ Yandex Cloud (файл .env рядом с main.py)
YANDEX_FOLDER_ID  — идентификатор каталога Yandex Cloud
YANDEX_MODEL      — yandexgpt-lite или yandexgpt (по умолчанию lite)
TELEGRAM_BOT_TOKEN — токен бота от @BotFather

Telegram-бот
------------
Тот же сценарий обработки файлов, что на сайте: загрузка Excel, обработка
с ИИ или без ИИ, готовый файл и протокол ошибок.

1. В Telegram откройте @BotFather, команда /newbot, скопируйте токен.
2. Впишите его в .env: TELEGRAM_BOT_TOKEN=...
3. Локально, из этой папки:

  python bot.py

На Render бот работает вместе с сайтом: добавьте TELEGRAM_BOT_TOKEN
в Environment и сделайте Redeploy. Webhook ставится при старте сервиса.
Шаблон один на сайт и бота. Заменить его в чате: /template
Страна и единица по умолчанию: /settings

ИИ-сопоставление столбцов
-------------------------
Кнопка «ИИ: сопоставить столбцы» отправляет заголовки листов в YandexGPT.
Модель возвращает соответствие «столбец → поле шаблона», после чего сервер
читает все строки и заполняет эталон. Если ИИ недоступен — используется
обычный поиск по ключевым словам.

Не публикуйте файл .env и не коммитьте API-ключ в репозиторий.

Публикация в интернете через Render
------------------------------------
1. Загрузите код в GitHub (репозиторий уже настроен).
2. Откройте https://dashboard.render.com → New → Blueprint
   и укажите репозиторий MANIVL/customs.
3. В настройках сервиса задайте секреты (Environment):
     YANDEX_API_KEY   = ваш API-ключ
     YANDEX_FOLDER_ID = идентификатор каталога
4. После деплоя Render выдаст ссылку вида
   https://tamozhenformat.onrender.com
   — её можно открыть в браузере с любого компьютера.
   Установка Python и bat-файл пользователям не нужны.

Постоянное хранилище
--------------------
Сервис использует persistent disk (DATA_DIR=/var/data): там хранятся
загруженный эталонный шаблон, метаданные и база артикулов. После перезапуска
или redeploy шаблон не нужно загружать заново.

В render.yaml указан план starter — на free у Render нет постоянного
диска, и локальные файлы очищаются при перезапуске. Для локального
запуска DATA_DIR не обязателен (по умолчанию backend/data).

Сервис может «засыпать» без трафика на некоторых тарифах;
первый заход после паузы может занять 30–60 секунд.

Для VPS/Docker:

  docker build -t tamozhenformat .
  docker run -p 8756:8756 -e YANDEX_API_KEY=... -e YANDEX_FOLDER_ID=... tamozhenformat

Как пользоваться
----------------
1. Раздел «Эталонный шаблон» — при необходимости замените шаблон своим
   файлом. Структура столбцов шаблона не меняется.
2. Раздел «Входные файлы» — загрузите один или несколько Excel-файлов
   (инвойс, спецификация, упаковочный лист и т.п.).
3. Нажмите «Скачать готовый файл».
   Страна происхождения берётся из файлов (Китай → CN, Италия → IT).
   Единица измерения — тоже из файлов (шт → ШТ, пар → ПАР, м → М).
   Если в файле значения нет, используется поле в настройках.
4. Чтобы обработать новую партию, нажмите «Удалить готовый файл»
   и загрузите новые входные файлы — перезапускать сервер не нужно.
5. Вкладка «Артикулы» — справочник из основной таблицы шаблона ВПР:
   поиск, добавление и правка записей. База сохраняется в articles.db.

Код МНР
-------
- «ЕАЭС RU С-…» → 01401
- «ЕАЭС N RU Д-…» → 01402
- «РОСС RU Д-…» → 01408
- любой другой номер → 01206
Если в строке два документа, они разносятся на два блока шаблона.

Классификатор стран мира
------------------------
Файл backend\data\countries.json (ISO 3166-1 / ОКСМ). По нему название
или код страны из входного файла превращается в alpha-2: Китай → CN,
Италия → IT. В веб-интерфейс классификатор не выводится.

Единицы измерения
-----------------
Файл backend\data\units.json. «шт» / pcs → ШТ, «пар» / pair → ПАР,
«м» / meter → М, «кг» / kg → КГ и т.д. Если единица в файле не найдена,
подставляется значение из настроек.

Замечания
---------
Шаблон на сервере один на всех, кто открывает этот адрес. Эталон и база
артикулов хранятся на постоянном диске (DATA_DIR). Для рабочего использования
добавьте авторизацию.

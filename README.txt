ТаможенФормат — веб-версия
==========================

Что это
-------
Веб-приложение для заполнения эталонного шаблона данными из входных
Excel-файлов. Приложение можно запустить локально или разместить на
облачном сервере, после чего пользователи открывают его обычной интернет-
ссылкой. Шаблон хранится в backend\data.

Установка
---------
Нужен Python 3.11 или новее.

  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt

Если рядом лежит папка python-runtime, можно запускать через run.bat
без отдельной установки пакетов.

Запуск
------
Дважды кликните run.bat — или в терминале:

  python main.py

Откроется браузер по адресу http://127.0.0.1:8756/

Остановка: Ctrl+C в окне терминала.

Доступ из локальной сети (другие компьютеры в той же сети):

  set APP_HOST=0.0.0.0
  set APP_PORT=8756
  python main.py

Затем откройте http://<IP-этого-компьютера>:8756/

Переменные окружения
--------------------
APP_HOST          — адрес прослушивания (по умолчанию 127.0.0.1)
APP_PORT          — порт (по умолчанию 8756)
APP_OPEN_BROWSER  — 0, чтобы не открывать браузер автоматически

Публикация в интернете через Render
------------------------------------
В репозитории уже есть файл render.yaml. Загрузите проект в GitHub, в Render
выберите New -> Blueprint и укажите этот репозиторий. Render автоматически
создаст веб-сервис, установит зависимости и выдаст ссылку вида
https://tamozhenformat.onrender.com. Пользователям достаточно открыть эту
ссылку: bat-файл и Python на их компьютере не нужны.

Для самостоятельного запуска на любом VPS используется Dockerfile:

  docker build -t tamozhenformat .
  docker run -p 8756:8756 tamozhenformat

После этого откройте порт 8756 на сервере и используйте его домен или IP.

Как пользоваться
----------------
1. Раздел «Эталонный шаблон» — при необходимости замените шаблон своим
   файлом. Структура столбцов шаблона не меняется.
2. Раздел «Входные файлы» — загрузите один или несколько Excel-файлов
   (инвойс, спецификация, упаковочный лист и т.п.).
3. Нажмите «Скачать готовый файл».
4. Чтобы обработать новую партию, нажмите «Удалить готовый файл»
   и загрузите новые входные файлы — перезапускать сервер не нужно.

Код МНР
-------
- «ЕАЭС RU С-…» → 01401
- «ЕАЭС N RU Д-…» → 01402
- «РОСС RU Д-…» → 01408
- любой другой номер → 01206

Если в строке два документа, они разносятся на два блока шаблона.

Замечания
---------
Шаблон на сервере один на всех, кто открывает этот адрес. На бесплатных
облачных тарифах локальные файлы могут очищаться при перезапуске сервиса,
поэтому эталонный шаблон может потребоваться загрузить повторно. Для
рабочего использования добавьте авторизацию и постоянное хранилище.
